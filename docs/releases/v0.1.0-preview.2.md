# ColmiRingVRCBridge v0.1.0-preview.2

Reliability update for the Windows x64 / COLMI R06 / VRChat OSC preview.

## Fixed

- OSC immediate Start/Stop crash (Issue #7), with output task, cancellation and sender lifetime coordinated through shutdown.
- Manual BLE connection versus application shutdown race (Issue #1).
- Reconnect operations leaving the UI busy indefinitely and unbounded BLE/GATT waits.
- Late native BLE completions overwriting current session/state.
- Persistence and diagnostic-log shutdown ordering.

## Improved

- Manual Scan/Connect preempts AutoReconnect. Manual Disconnect suppresses automatic retries until a manual connection or Auto off/on.
- Cancellation and cleanup ownership, connection-stage diagnostics, and regression/lifetime/priority/serialization test coverage.

OSC destination, parameter paths, Float/Int options and stale-heart-rate behavior remain compatible: stale HR stops new BPM transmissions, so VRChat may retain its last received value.

## Known limitations

- Only COLMI R06 is validated. Packages target Windows x64.
- BLE/GATT behavior depends partly on Windows/WinRT and the Bluetooth driver.
- Controlled distance-induced link-loss recovery is not tested; this is a non-blocking hardware-validation note.
- Automatic HR measurement-session recovery after remove/re-wear is not yet guaranteed.
- Experimental reboot and post-reboot HR recovery are deferred to [Issue #8](https://github.com/orzkwsk/ColmiRingVRCBridge/issues/8), which remains open. Reboot UI and commands are excluded.

## Package

- `ColmiRingVRCBridge-0.1.0-preview.2-win-x64.zip`
- Matching `.sha256` checksum file

Extract the ZIP and run `ColmiRingVRCBridge.exe`. The package includes its .NET runtime; no separate runtime installation is required.

This software is experimental and is not intended for medical diagnosis, treatment, or safety-critical monitoring.
