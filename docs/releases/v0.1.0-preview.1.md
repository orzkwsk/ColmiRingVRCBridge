# ColmiRingVRCBridge v0.1.0-preview.1

First public preview of ColmiRingVRCBridge.

## Scope

This release is intended for VRChat users and developers who want to route realtime heart-rate telemetry from a QRing-compatible COLMI ring into VRChat OSC.

Validated hardware for this preview:

- COLMI R06

R02/R10 are protocol-compatible references used during development but are not claimed as validated devices in this release.

## Included

- BLE scan/connect and direct reconnect to the last successful ring.
- Realtime BPM acquisition.
- Heart-rate freshness/stale tracking independent from BLE link state.
- Battery percentage and charging state.
- Local battery-history graph data.
- VRChat OSC Float/Int output.
- Dummy BPM mode for avatar testing.
- Diagnostics for GATT notifications, protocol validity, HR packet flow and poll failures.
- Reliability hardening around reconnect and telemetry polling.

## Important behavior

When HR becomes stale, this preview stops sending new BPM values over OSC until fresh telemetry returns. VRChat may retain the last value already received. This preview does not automatically send zero and does not publish a separate validity parameter.

## Known limitations

- Automatic recovery from an HR measurement-session stall after remove/re-wear is not yet guaranteed.
- Recovery escalation from session re-arm to GATT/BLE reopen remains under R06 hardware validation.
- Windows BLE/GATT timeout behavior is partly dependent on WinRT.
- Only Windows x64 is packaged by the release workflow.

## Package

The GitHub Release workflow produces:

- `ColmiRingVRCBridge-0.1.0-preview.1-win-x64.zip`
- matching `.sha256` checksum file

The package is self-contained and does not require a separately installed .NET runtime.

## Disclaimer

This software is experimental and is not intended for medical diagnosis, treatment, or safety-critical monitoring.
